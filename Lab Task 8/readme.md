# Blog Cards Project

A simple and responsive blog cards display using vanilla JavaScript, HTML, and CSS.

## Features

- Display blog articles in card format
- Responsive grid layout
- Hover effects on cards
- Dynamic content generation from JSON data
- 9 blog posts with Pakistani authors

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript


## How It Works

### Data Structure
The project uses a JavaScript array of objects (`blogData`) containing blog information:
- `id`: Unique identifier
- `title`: Blog post title
- `author`: Author name
- `description`: Brief description
- `image`: Image URL
- `date`: Publication date

### JavaScript Logic
1. Stores blog data in an array
2. Selects the container element
3. Loops through each blog post using `forEach()`
4. Creates card elements dynamically
5. Adds HTML content using template literals
6. Appends cards to the container
