## 🎯 About

This open-ended lab project is a comprehensive Pokémon data dashboard that fetches and displays real-time information from the **PokéAPI**.  
It provides an intuitive interface to explore Pokémon species, their types, evolution chains, moves, and items—all presented in a modern, visually engaging design.

**Lab Objective:**  
To integrate a public API using **HTML**, **CSS**, **Bootstrap**, and **JavaScript** to practice data fetching, dynamic rendering, and responsive UI design.

---

## 🔌 API Information

**API Used:** [PokéAPI](https://pokeapi.co/)

- **Type:** Public RESTful API  
- **Authentication:** None required  
- **Rate Limit:** None  
- **Documentation:** [https://pokeapi.co/docs/v2](https://pokeapi.co/docs/v2)  
- **Base URL:** `https://pokeapi.co/api/v2`

**Why PokéAPI?**
- Free and open-source  
- No authentication required  
- Comprehensive Pokémon data  
- Ideal for frontend integration practice

## ✨ Features

### 🎮 Core Functionality
- **Pokémon Browser:** Explore 20+ Pokémon with detailed stats  
- **Smart Search:** Find Pokémon by name or ID  
- **Type Explorer:** Browse all Pokémon types visually  
- **Evolution Chains:** Interactive evolution visualization  
- **Move Database:** Explore moves with power and accuracy  
- **Item Catalog:** Browse Pokémon items with icons  

### 🎨 UI/UX Features
- Fully responsive (mobile-first)  
- Modern **Glassmorphism** design  
- Smooth animations and hover effects  
- Custom scrollbars and transitions  
- Clear loading states and error messages  

### 💡 Interactive Elements
- Real-time search  
- Animated evolution arrows  
- Stat and type badges  
- Hover effects on sprites
